# 내 귀 보정 EQ(주파수별) 설계 (2026-11-21)

청력 측정 EQ의 2단계. 배경은 `2026-11-20-hearing-eq-review.md`, 1단계(좌·우 균형)는 `2026-11-21-ear-balance-design.md`.

## 목적
- 사용자가 원한 것: "덜 들리는 부분을 EQ로 채우기". 몇 kHz까지 들리는지 재는 것이 목적이 아님.
- 왼쪽·오른쪽 귀마다 주파수별로 겨우 들리는 크기(역치)를 재서, 정상보다 덜 들리는 주파수를 조금 올려 주는 **"내 귀 보정" 층**을 만들고, 폰에 거는 어떤 EQ든 그 위에 더한다.

## 목표 / 하지 않을 것
- 목표: 측정(양쪽 귀 × 7개 주파수) → 결과 그래프 → 보정 층 저장 → 안드로이드 앱에서 귀마다 따로 적용, 켜고 끄기, 세기 조절, 다시 재기.
- 하지 않음(이번엔): PC(APO `Channel: L/R`)·Wavelet 내보내기, 여러 결과 저장(기기별 프로필), 마이크로 주변 소음 재기, 12kHz 위 측정, 의료용 정확도.
- 실패로 볼 것: 정상 귀인데 저음·고음을 크게 올리는 EQ(기준 곡선을 안 빼면 생김), 소리가 깨질 만큼 올리는 것, 시험 소리에 걸어 둔 EQ가 섞이는 것, 시험 중 갑자기 큰 소리.

## 방식 결정
- 사용자 선택: **A. 겨우 들리는 크기 재기**(들리면 [들려요], 들리면 줄이고 안 들리면 키움).
- 고르지 않은 것: B. 크기 맞추기(다른 높이 소리끼리 크기 비교는 같은 사람도 ±5dB 흔들려 EQ로 쓰기에 불안정).

## 측정 (내 판단으로 정한 값)
- 주파수: 1000 → 2000 → 4000 → 8000 → 500 → 250 → 125Hz(첫 1kHz는 연습 겸), 마지막에 1000Hz를 한 번 더(흔들림 확인). 왼쪽 귀 전부 → 오른쪽 귀 전부.
- 소리: 사인파 0.25초 × 3번(0.15초 간격), 20ms 페이드, 한쪽 귀만(`ChannelMergerNode`의 한 입력). 시험 전 0.3초 무음(블루투스). 기존 `tonePlayer.ts` 옆에 단발 재생 함수를 둔다.
- 크기 단위: dBFS(디지털 크기). 실제 음압은 모르므로 **상대값만** 쓴다. 시작 −40dBFS, 최대 −10dBFS(그 이상은 안 냄, 안전), 최소 −100dBFS.
- 계단법(수정 Hughson-Westlake): 들림 → −10dB, 안 들림(2.5초 안에 안 누름) → +5dB. 올라가는 단계에서 같은 크기에 3번 중 2번 들리면 그 크기가 역치. 한 주파수에 최대 20번 들려주고 못 정하면 마지막 올라간 크기들의 평균.
- 소리 간격 1~2.5초 무작위(박자에 맞춰 누르기 방지). 가짜 문항(소리 없음) 약 15%: 거기서 누르면 기록, 한 귀에 3번 넘으면 결과 화면에 "소리가 없을 때 누른 적이 많아요" 경고.
- 마지막 1kHz 두 값 차이가 10dB를 넘으면 "결과가 흔들려요, 다시 재 보세요".
- 걸린 폰 EQ·균형은 시험 동안 `setBypass(true)`, 끝나거나 닫으면 되돌림(1단계와 같음).
- 시험 전: 쓰는 기기(내 기기 측정치 목록에서, "모름" 가능) 고르기, 폰 볼륨을 평소 크기로 두고 시험 중 바꾸지 않기, 조용한 곳, 유선 권장(무선은 작은 소리를 꺼 버릴 수 있음), 이어폰 앱의 효과·노이즈 캔슬링 안내. 도움말 접기 안에.
- 시간: 양쪽 약 5~8분. 중간에 닫으면 처음부터.
- 계산(계단법 다음 크기·역치 판정·가짜 문항 처리)은 순수 함수 + 테스트. 재생 순서의 무작위는 `rand` 인자로 받아 테스트에서 고정.

## 보정 계산 (순수 함수, 내 판단으로 정한 값)
1. 귀마다 상대 역치: 각 주파수 역치 − 그 귀의 500·1k·2k 역치 평균(좌·우 음량 차이는 1단계 균형이 따로 맡음).
2. 정상 귀 기준을 뺀다: 같은 방식으로 상대값으로 만든 표준 역치 곡선(ISO 389-7 등)을 뺀다. **표준 수치는 구현 때 공개 자료로 확인해서 출처와 함께 넣는다(기억으로 넣지 않음).** 확인할 수 없으면 멈추고 사용자에게 알림.
3. 기기 몫을 뺀다(기기를 골랐을 때만): 그 측정치가 같은 종류 Harman 타깃에서 벗어난 만큼(1옥타브 스무딩, 기존 `similarity.prepare`·`targets.ts`)을 뺀다. 5kHz 위는 장비와 실제 귀 차이가 커서 절반만.
   - **주의사항(사용자 요청)**: 측정치는 측정자·장비(리그)·보정 방식마다 기준이 달라 같은 기기도 몇 dB씩 다르다. 그 차이가 "덜 들림"으로 섞여 원음을 해칠 수 있다. 기기를 고르는 칸 바로 아래에 짧은 경고("측정치는 측정자마다 기준이 달라 원음을 해칠 수 있어요")를 늘 보이고, 자세한 설명은 도움말에. "모름"을 고르면 기기 몫을 빼지 않는다(그 기기 소리가 결과에 섞인 채로 그 기기 전용이 됨). 결과 화면에도 어떤 측정치(출처)로 뺐는지 표시.
4. 덜 들림 = 위 결과(양수 = 정상보다 덜 들림). 측정 오차 범위 5dB까지는 0으로 본다.
5. 올릴 양 = (덜 들림 − 5) × 세기(기본 50%), 0~+6dB로 자름. 깎기는 하지 않음(더 잘 들리는 건 그대로).
6. 곡선으로: 7개 점을 로그 주파수로 이어 127개 주파수에서 값을 구하고, 125Hz 아래는 125Hz 값, 8kHz 위는 줄여서 12kHz에서 0.
7. 안드로이드에 걸 때: 채널마다 (걸어 둔 EQ의 127밴드 값 + 그 귀의 보정 층), 프리앰프는 두 채널 중 가장 큰 부스트만큼 낮춤(소리 깨짐 방지), 균형(1단계) 감쇠는 그대로 더함.

## 저장
- localStorage `ear.profile` = `{ measuredAt, device: { label, measurementId? }, freqs, left: 역치[], right: 역치[], falseAlarms: {left, right}, strength, on }`. 역치 원값을 저장해서 계산 규칙이 바뀌어도 다시 재지 않게 한다. 백업에는 넣지 않음(1단계와 같음).
- 안드로이드는 마지막으로 건 채널별 127밴드 값을 SharedPreferences에(재부팅 복원).

## 적용 (안드로이드 앱)
- 지금은 양쪽에 같은 EQ(`setPreEqAllChannelsTo`) → 채널별(`setPreEqByChannelIndex` 계열, 구현 때 공식 문서로 메서드 이름 확인). 플러그인 `apply`에 오른쪽 게인 배열(선택)을 더하고, 없으면 지금처럼 양쪽 같음.
- 보정 층이 켜져 있으면 EQ를 걸 때 함께, EQ를 끄면 "내 귀 보정"(평평한 EQ + 층 + 균형)으로 남는다. 1단계의 "균형만" 상태는 이름을 "내 귀 보정"으로 합친다(균형만 켜져 있어도 같은 이름).
- 켜고 끄기·세기를 바꾸면 지금 상태에 바로 다시 건다(값만 바뀌어 끊김 없음).

## 화면
- 설정: "내 귀 균형" 줄 아래 "내 귀 보정" 줄: 상태("아직 안 쟀어요" / "11월 21일 · 기기 이름"), 켜짐/꺼짐(앱만), [재기]. 결과가 있으면 줄을 누르면 결과 팝업.
- 측정 팝업(`EarEqDialog.tsx`): 준비(기기 고르기 + 안내) → 시험("왼쪽 귀 · 3 / 8", 큰 [들려요] 버튼, 손가락 화면은 화면 아래 절반을 차지할 만큼 크게, 스페이스바도 됨) → 결과.
- 결과 팝업: 귀마다 덜 들림 그래프(주파수별 막대 또는 점, 왼쪽·오른쪽 색 구분) + 올릴 양 곡선, 세기 슬라이더(0~100%, 기본 50%), 경고, [저장하고 적용]. 그래프는 기존 Chart.js 사용.
- EQ 화면 상태 줄: 보정이 켜져 있으면 "· 내 귀 보정".
- 웹: 측정·결과 보기·저장은 되고, 적용은 "안드로이드 앱에서 적용돼요".

## 작업 순서(제안)
1. 순수 계산: 계단법·가짜 문항·역치 판정(`src/hearingTest.ts`)과 보정 계산(`src/earEq.ts`, 표준 역치 수치 확인 포함) + 테스트
2. 안드로이드 채널별 EQ(플러그인·서비스) + `eqDevice.ts` 채널별 127밴드 + `eqEngine.ts` 층 더하기, CI 빌드 확인
3. 시험 소리·측정 팝업
4. 결과 팝업(그래프·세기)·설정 줄·상태 줄, 폰 확인

## 남겨 둔 것(만들면서 정함)
- 결과 그래프 모양 세부, 시험 화면 문구.
- 기기 몫 빼기에서 기기 종류와 타깃이 맞지 않을 때(예: 이어폰인데 헤드폰 측정치를 고름) 처리: 빼지 않고 경고.
