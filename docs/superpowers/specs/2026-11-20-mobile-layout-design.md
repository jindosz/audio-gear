# 모바일 레이아웃 설계 (2026-11-20)

## 왜
폰에서는 Wavelet으로 EQ가 걸리는 것을 확인했으니 폰에서도 앱을 쓸 수 있어야 한다. 지금은 PC용 3단(메뉴 72px | 목록 260px | 그래프)이 폰에도 그대로 나와 그래프 칸이 몇 글자 폭밖에 안 된다. 화면 폭에 따른 CSS(`@media`)가 하나도 없다.

## 목표 / 안 할 것
- 목표: 폰에서 **그래프가 위쪽 가운데**에 크게 보이고, **아래 목록에서 기기·측정치를 골라** 바로 그래프에 띄운다.
- 안 할 것(이번 범위 밖): EQ 화면·팝업들의 폰 최적화(다음 단위), 손가락으로 끌어 올리는 서랍 동작.
- 실패로 볼 것: PC 화면 배치가 바뀌거나 망가지는 것.

## 방식 비교
- A. 위아래 고정 분할: 가장 단순하지만 목록이 반쪽이라 검색 결과가 몇 줄만 보임.
- **B. 아래 서랍(펼치기/접기) — 선택**: 기본은 반반, 손잡이를 누르면 목록이 화면 대부분으로 펼쳐짐. 그래프가 늘 보이면서 목록을 넓게 쓸 수 있음.
- C. 아래 탭 전환(목록 | 그래프): 고르면서 그래프를 바로 볼 수 없어 제외.

## 정한 것
- 폰 기준: 화면 폭 768px 이하(Claude 판단).
- 맨 위 한 줄: 왼쪽 메뉴 대신 EQ·설정 버튼(Claude 판단). 그 아래 비교 탭과 그래프.
- 목록 맨 위를 양쪽으로 나눠 **헤드폰 | 이어폰** 전환(사용자 결정). 그 아래 검색·필터·`+`, 선택됨·보유·찜·전체 목록은 PC와 같은 부품.
- 목록 위 손잡이(▲/▼)를 누르면 펼치기/접기. 펼친 상태는 다시 열면 기본(반반)으로(Claude 판단).
- 목록 폭 조절 손잡이(`ResizeHandle`)는 폰에서 숨김.

## 작업 단위
1. 폰 폭에서 위아래 배치 + 위 메뉴 줄 + 목록 위 헤드폰/이어폰 나눔 (CSS 위주)
2. 펼치기/접기 손잡이
