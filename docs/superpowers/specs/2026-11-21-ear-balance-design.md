# 내 귀 균형(좌·우 음량 맞추기) 설계 (2026-11-21)

청력 측정 EQ의 첫 단계. 배경과 나머지 단계는 `2026-11-20-hearing-eq-review.md`.

## 목적
- 왼쪽·오른쪽 귀(와 기기)의 음량 차이를 1분 안에 재서, 폰 전체 소리를 **듣기에 가운데**로 맞춘다.
- 사용자가 원한 것: 청력 측정 EQ를 만들고 싶고, 그 첫 단계로 좌·우 균형부터.

## 목표 / 하지 않을 것
- 목표: 측정 화면 → 결과 값 하나(dB) 저장 → 안드로이드 앱에서 폰 전체 소리에 적용, 켜고 끄기, 다시 재기.
- 하지 않음(이번엔): 주파수별 보정 EQ, 겨우 들리는 크기(역치) 재기, PC(APO)·Wavelet 내보내기, 기기별로 값 따로 저장, 마이크 소음 측정.
- 실패로 볼 것: 균형을 맞추려고 소리를 **키워서** 깨지는 것, 시험 소리에 기존 EQ·균형이 섞여 잘못 재는 것.

## 방식 결정
- 사용자 선택: **A. 가운데 맞추기**. 평소 듣는 크기의 순음을 양쪽에 틀고, 슬라이더로 소리가 머리 한가운데서 들리게 맞춘다.
- 고르지 않은 것: B. 겨우 들리는 크기 재기(3~5분, 조용한 곳 필요, 무선 이어폰은 작은 소리를 꺼 버림, 평소 크기의 차이와 다를 수 있음). 나중에 주파수별 보정 EQ에서 쓴다.

## 측정 (내 판단으로 정한 값)
- 소리: Web Audio 사인파, 0.4초 켜짐 / 0.3초 꺼짐 반복(끊어지는 소리가 위치를 잡기 쉬움), 켜고 끌 때 30ms 페이드. 크기는 고정 −20dBFS, 사용자가 시험 전에 폰 볼륨을 평소 듣는 크기로 맞춤.
- 왼쪽·오른쪽 따로 `GainNode` → `ChannelMergerNode`(왼쪽 0, 오른쪽 1).
- 슬라이더 값 = "오른쪽을 왼쪽보다 몇 dB 크게"(−12~+12, 0.5dB 단위). 소리는 **큰 쪽을 줄이는** 방식으로만 냄(양수면 왼쪽을 그만큼 낮춤).
- 순서: 1kHz → 500Hz → 4kHz → 다시 1kHz → 500Hz → 4kHz(6번). 매번 슬라이더 시작 위치를 ±3~6dB 사이 무작위로(0에 머무는 버릇 방지). [다음]으로 넘어감.
- 결과 = 6번 평균(0.5dB 단위로 반올림). 같은 주파수의 두 번 값 차이가 3dB를 넘는 게 있으면 "값이 들쭉날쭉해요, 다시 재 보세요" 안내(결과는 저장 가능). |결과| ≥ 10dB면 "차이가 커요, 이비인후과 진료를 권해요".
- 시험 시작 전: 폰 EQ나 균형이 걸려 있으면 잠깐 끄고, 시험이 끝나거나 닫으면 원래대로 되돌림.
- 안내(도움말 접기 안): 의료용 검사 아님, 조용한 곳, 이어폰을 제대로 착용, 삼성 사운드 효과·이어폰 앱 효과 끄기.
- 계산(시작 위치, 평균, 흩어짐 판정, 진료 권유 판정, 채널별 감쇠)은 순수 함수 `src/earBalance.ts` + 테스트.

## 저장
- localStorage `ear.balance` = `{ db: number, on: boolean, measuredAt: string }`. 백업에는 넣지 않음(귀·기기마다 다르고 값 하나라 다시 재면 됨).
- 안드로이드 쪽은 마지막 값을 SharedPreferences `system_eq`에 함께 저장(재부팅 복원에 필요).

## 적용 (안드로이드 앱)
- `SystemEqPlugin.apply`에 `balanceDb` 추가. `SystemEqService`는 `setInputGainAllChannelsTo` 대신 채널 0(왼쪽)·1(오른쪽)에 `setInputGainbyChannelIndex`로 각각 `inputGain + 감쇠`를 건다(양수면 왼쪽 −db, 음수면 오른쪽 −|db|). 채널이 하나뿐이면 균형 무시.
- 걸어 둔 EQ가 없어도 균형이 켜져 있으면 평평한 EQ(밴드 0dB)로 서비스를 돌려 균형만 건다. 알림·상태 줄 이름은 "내 귀 균형".
- EQ를 끄면(`turnOffPhoneEq`) 균형이 켜져 있을 때는 "균형만" 상태로 남고, 균형을 끄면 서비스가 멈춘다.
- 균형 값이나 켜짐이 바뀌면 지금 상태(EQ 또는 균형만)에 바로 다시 건다(값만 바뀌므로 끊김 없음).

## 화면
- 설정 → "내 귀 균형" 줄: 값("오른쪽 1.5dB 낮춤" / "가운데" / "아직 안 쟀어요"), [켜짐/꺼짐] 토글(안드로이드 앱만), [재기].
- EQ 화면 맨 위 `PhoneEqStatusBar`: 균형이 켜져 있으면 이름 옆에 작게 "균형 R −1.5dB".
- 측정 팝업(`EarBalanceDialog.tsx`): 준비 안내 → 6번 맞추기(진행 "3 / 6", 주파수 표시, 슬라이더 "왼쪽 ◀ ▶ 오른쪽", [다음]) → 결과(값, 경고, [저장하고 적용] / [닫기]).
- 웹(PC·폰 브라우저)에서도 측정·저장은 되고, 적용 토글 대신 "안드로이드 앱에서 적용돼요" 한 줄.

## 남겨 둔 것(만들면서 정함)
- 슬라이더 모양·문구 세부, 손가락 화면 크기는 기존 규칙(`pointer: coarse` 44px 이상).
- 서비스 쪽 "균형만" 상태를 기존 `applied` 상태와 어떻게 합칠지(`eqEngine.ts`의 `useEqStatus`가 균형만일 때 무엇을 보여줄지).
