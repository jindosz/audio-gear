## 지난 채팅에서 배운 것 (같은 실수 반복 방지)
- 사용자의 짧은 답("안들린다")은 뜻이 두 가지일 수 있음 → 실험 결과는 "꺼졌다/그대로다"처럼 정확히 답해 달라고 하고, 모호하면 되물을 것
- 프로그램 이름·옵션 이름을 추측해서 안내하지 말 것(Configurator → 실제 이름은 `DeviceSelector.exe`). 실제 화면을 캡처해 달라고 하고 보고 안내
- 사용자 PC의 파일은 Write 도구로 쓴 내용이 되돌아간 적이 있음 → 외부 파일은 PowerShell로 쓰고 다시 읽어 확인
- 린터는 ESLint가 아니라 `oxlint`(`npm run lint`). 타입 검사는 `npx tsc -b`
- 원격 접속(Remote Control) 세션에서는 `preview_start`로 launch.json 서버를 못 켬 → PowerShell로 서버를 백그라운드 실행 후 주소로 열기
